How it works

A little home for everything you saved.

Keep links to Instagram posts, TikTok videos, and web pages in one searchable library. Add folders and notes to find them again.

Try the demo ↗

Sample saves. No account needed.

    Find it again

    When dinner rolls around, search for lemon. Little Archive looks in titles, notes, and any captions it has.

Little Archive is open source. Follow the setup guide on GitHub to run it on your own computer or server.
